# 設計書22: UIリスタイル「スコアブック」（モダンミニマル＋紙色・明朝・墨）

status: 承認済みの方針で着手（2026-11-09）
decided: オーダー画面の試作（コミット 1771d35・Claude Design モック）をユーザーが承認し、データ画面へ広げると決定
supersedes: design-19「デーゲーム・フルNB」の面・枠・影・カード・トップバーの節（データ画面のみ）／design-16 の書体3役のうち本文と数字の書体

## 0. 背景と決定

オーダー画面を「モダンミニマル（白・余白）を土台に、スコアブック風（紙色・明朝・墨）を少し足す」見た目で作り直し、
`Components/scorebook.uss`（画面ルートの `.sbk` の中だけに効く）として試作した。ユーザー承認を受けて他画面へ広げる。

ユーザー決定（2026-11-09）:

| # | 論点 | 決定 |
|---|---|---|
| 1 | トップバー | **紙色に溶かす**。黒い電光掲示板の島（design-19 §8-2）は廃止。校名・週・部費・名声などは紙色の地に明朝＋Noto で載せる |
| 2 | 範囲 | **データ画面だけ**。試合中の画面（MatchLive の HUD・交代パネル・3D対決ビュー・2D盤面）は今の見た目のまま |
| 3 | 書体・調子の色 | **全画面で切り替える**（試合中の画面も含む）。本文も数字も Noto Sans JP、名前・見出しは明朝。調子5色は新色 |
| 4 | 主ボタン | **応援団赤 #E8452E のまま**（「今週を進める」等）。スクールカラーの差し色はオーダー画面だけの演出に留める |

既に決まっていて変えないもの:
- ランク S〜G は今のレター画像（`Images/ranks/`）。色覚対応の機能色なのでスキン都合で変えない（design-19 §0）
- 掲示板のドット書体（DotGothic16）は試合中のスコア部品（LineScorePanel / ScoreBug）の中だけに残る

## 1. 効く範囲の切り方

| 何を | どこまで | 仕組み |
|---|---|---|
| 面・線・カード・行・トップバー・2択切替 | データ画面だけ | 画面ルートに `sbk` クラスを付けた画面の中だけで効く（`scorebook.uss`）。試合中の画面は付けない＝今の昼NBのまま |
| 書体（Noto Sans JP） | 全画面 | 既定フォント3箇所（`tokens.uss .ui-root`／`KokoSimTheme.uss .root`／`KokoSimTextSettings.asset`）と `.f-body*` `.f-num*` を Noto に向ける |
| 調子5色 | 全画面 | `ConditionFace` の既定色・`tokens.uss --cond-*`・`ConditionLabels.ColorHex` の3面を同時に変える |
| 主ボタン | 全画面 | 応援団赤のまま（`--color-cta`） |

`.sbk` はスキン切替の唯一のスイッチ。部品（components.uss）の新スキン版は `.sbk .部品` のセレクタで書き、
旧スキン（試合中の画面）用の定義はそのまま残す。

## 2. トークン（scorebook.uss の `.sbk`）

オーダー画面で確定した値をそのまま全データ画面の正典にする。

| 用途 | 値 |
|---|---|
| 画面背景（紙色） | `#F2EFE8` |
| カード・パネル | `#FFFFFF`、枠 `#E3DFD5` 1px、ホバー枠 `#D9D4C8` |
| 区切り線 | `#D9D4C8`（ヘッダー下）／`#ECE8DF`（パネル内・横棒の下地） |
| 文字 | 本文 `#1D1B18`／補足 `#6F6A60`／学年・投打 `#4F4A42`／負け `#7A756C` |
| 選択 | 墨 `#2F2C27` の2px枠（通常時も透明な枠ぶんを確保してずれない） |
| 2択切替 | 土台 `#E6E2D8`、選ばれた側は白地＋1px枠 |
| 怪我タグ | 地 `#F9E3E0`／文字 `#8A1F1A` |
| 守備位置チップ | 投・捕・内野・外野・指の5系統（scorebook.uss の `--sbk-pos-*`） |
| 角丸 | カード10／パネル12／チップ4〜8／背番号布3 |
| 主ボタン | 応援団赤 `#E8452E`（全画面）。オーダー画面だけスクールカラー（`SchoolAccent`） |

調子5色: 絶好調 `#E0605A`／好調 `#E8904A`／普通 `#E3BD3C`／不調 `#7FA8D6`／絶不調 `#4F6FA8`、目と口 `#2A2622`。

## 3. 書体（design-16 書体3役の改訂）

| 役割 | 書体 | クラス |
|---|---|---|
| 名前・校名・大会名・見出し・打順番号 | Shippori Mincho B1（ExtraBold / Bold） | `.f-display` / `.f-display-lg`（変更なし） |
| 本文・ラベル・ボタン | Noto Sans JP Regular / Medium / Bold | `.f-body` / `.f-body-md` / `.f-body-bd` |
| 数字 | Noto Sans JP Regular / Bold | `.f-num` / `.f-num-bd`（クラス名は残し、向き先だけ Noto に変える） |
| 掲示板（試合中のスコア部品の中だけ） | DotGothic16 | `.f-dot`（変更なし） |

- 3役 → 実質2役（明朝＋Noto）。Noto は和文を持つので「数字＋和文の混植は Label を分ける」規則は不要になる（既存の分割はそのままでよい）
- Plex と Oswald は全画面の切替（G0）が終わったら使わない。アセットの削除は G3 で判断する
- 投球回の ⅓ ⅔ はどの書体にも字形が無い。整数＋右上の小さな「1/3」で組む（オーダー画面の先発カードと同じ）
- 共通部品が自分で書体を指定している所（移行レジストリ）が残ると Plex が混じる。各ゲートで**書体の監査**
  （画面上の文字要素の解決済みフォントを数える。`OrderRestyleShooter.AuditFonts` と同じ方法）を回す

## 4. 部品（`.sbk` 版）

| 部品 | 新スキンでの見た目 |
|---|---|
| `.card` | 白・1px枠・角丸10。芝の塗り見出し帯とベタ影は廃止。見出しは小見出しラベル（12px・補足色）か明朝の題字 |
| `RowWell` + `RowPanel` | 井の地は廃止（紙色の上に白カードの行を6px間隔で積む）。選択は墨の2px枠 |
| `PlateHeader` | 塗りプレートは廃止。見出し文字だけ（明朝）＋必要ならヘッダー下の1px線 |
| TopBar（`.sb2` / `.nav`） | 紙色の地。校名は明朝、週・部費・名声・信頼度は Noto。電光掲示板ストリップ（`.sbs`）は出さない。ナビは文字タブ＋選択中に下線（墨） |
| `SegmentedControl` / `Switch` | 2択切替（`.sbk-seg`）に統一 |
| `NumberBadge` | 背番号布（`NumberPatch`） |
| 守備位置チップ | `PositionChip`（系統色）。出してよい位置の規則（CLAUDE.md UI原則の注記）は不変 |
| 比較表 | `StatBarRow`（ランク＋数値＋横棒）。自チーム側＝差し色（オーダー画面）／それ以外の画面は墨 |

## 6. 正典の改訂案（G4で反映）

- **②強調は希少資源**: CTA は応援団赤で1画面1箇所（変更なし）。選択は墨の2px枠（桜の面は廃止）。操作色（空青）は2択切替の白地＋枠に置き換え。スクールカラーはオーダー画面だけ
- **④区切りは余白と背景色で**: 「紙色の地と白カードのコントラストで分ける。線は1pxの淡い線だけ（ヘッダー下・パネル内）」へ戻す（design-19 のインク太枠とベタ影は撤去）
- **書体3役**: 上の §3 の2役＋掲示板へ改訂
- ①密度・③数字・⑤トークン・⑥状態・⑦操作は現行のまま

## 7. リスク・未決（実装で勝手に決めない）

| 項目 | 論点 |
|---|---|
| 行高と字幅 | Noto は Plex より字面が大きく、Oswald（コンデンス）より数字の幅が広い。密な表（選手一覧・記録）で列が足りなくなる可能性。G0 の棚卸しで実測し、列幅の調整か級数の調整かを画面ごとに相談する |
| トップバーの情報量 | 電光ストリップに出していた内容（週・日付など）を紙色のバーのどこに置くか。G1 でワイヤー3案を出して選んでもらう |
| ランク画像と白カード | レター画像は白地で細く見える（オーダー画面で確認済み）。サイズの下限を部品で決めるかは G2 で相談 |
| 試合中の画面との境目 | 試合前（MatchPreview）→ 試合中（MatchLive）でスキンが切り替わる。違和感があれば G3 で相談 |
| リポジトリ容量 | Noto の SDF 3枚（各約35MB）を追加済み。Plex/Oswald を消すかは G4 |

## 8. 検証

- 各ゲートで画面ごとのバッチスクショ（`OrderRestyleShooter` の型）→ 自己レビュー → ユーザー目視
- 書体の監査（Noto / 明朝 / 試合中スコア部品の DotGothic 以外が0）
- 純粋な見た目の変更＝エンジン・data・帯への影響ゼロ。Assets を触るので `tools/check-unity-compile.sh` は毎回

## 9. 進捗

- **G0 完了（2026-11-09）**: 既定フォント3箇所と `.f-body*` `.f-num*`・移行レジストリを Noto Sans JP へ向け替え
  （Regular→Regular／Medium→Medium／SemiBold→Bold／Oswald Medium→Regular／Oswald SemiBold→Bold）。
  調子5色を4面（tokens `--cond-*`／KokoSimTheme `.cond--*`／`ConditionFace`／`ConditionLabels.ColorHex`）で同期。
  書体の監査は `ScreenshotBatch` が `<prefix>fonts.txt` に書く（`FontAudit`）。データ18画面で Plex・Oswald ゼロ。
  旧書体と並べた比較で、G0 起因の崩れは無し。以下は旧書体でも同じだった既存の問題（G2/G3 で扱う）:
  経営「資金」の説明2行の折り返し／試合開始前のレーダーのラベルが図に重なる／試合中の投手行（投 10 … 22球）の下端が欠ける／
  戦術カード「コントロール重視」の語中での折り返し
- **G1 完了（2026-11-09）**: トップバーは案A（1段＋ナビ。ユーザー選択）。データ17画面のルートへ `sbk` と
  `scorebook.uss` を付けた。方式は2段：①昼NBのトークン（面・文字・線・枠幅・ベタ影・角丸・役割色）を `.sbk` の中で読み替え
  ②`--ink` は文字色も兼ねるので、インク枠の器（card / row-panel / plate-header / hm-hero / tpm-card ほか約40セレクタ）を
  `.sbk` 付きで淡い1px枠へ上書き。電光ストリップは升目の仕組みのまま、マスの地と枠を消して明朝の日付行にした。
  ナビは文字タブ＋墨の下線。操作色（空青）と選択色（桜）は墨へ。
  **罠**: オーダー画面用の `Label` の余白リセットを `.sbk` に置いたら全データ画面で文字がくっついた
  ＝画面固有のリセットは画面ルート（`.lu-root`）に置く。
