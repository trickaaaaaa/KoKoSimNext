# 設計書10: 特殊能力（スキル）詳細設計

選手の"顔"を作る質的な個性。設計書02 §4.5のスキル概念を体系化する。

## 0. 設計原則（最重要・切り分けの鉄則）

- **有無のみ（ランクなし）**: スキルは「持つ／持たない」のフラグ。強弱はパラメータ（連続値）が担う
- **後天取得あり**: 生成時保有に加え、練習・イベントで習得できる。まれに克服も
- **パラメータ／精神力システムで表現できるものはスキルにしない（鉄則）**:
  - 走塁の巧拙 → バント・盗塁・走塁判断パラメータ（設計書01）
  - 送球の正確さ・肩 → 送球精度・肩パラメータ
  - **左右の相性 → 打者の「対左投手経験（慣れ）」＋左投手の希少性（設計書02 §2.3）で既に表現**。スキル化しない
  - 逆境／大舞台／満塁 等の**状況の重さそのもの** → 精神力×プレッシャー指数（設計書02 §3）で算出。スキル化しない
  - 制球の安定・被本塁打の傾向 → コントロール・球種の質パラメータ
  - 守備の巧拙（併殺・リード）→ 守備・肩・リードのパラメータ（守備系スキルは issue #907 で廃止）
- スキルに残すのは、上記のどれでも出せない**質的な癖・非線形な挙動・チームへの波及**だけ
- 効果は控えめに。多数の弱スキルの集合体にしない（元祖の硬派さ）

### 0.1 チャンス／ピンチの例外（issue #907・2026-11-14 監督決定1）

「チャンス◎×」「ピンチ◎×」は**状況補正そのものではなく、プレッシャーの受け止め方の癖**としてスキルに置く。
精神力と二重計上しないよう、効かせ方を次の1点に限る:

- 精神力×プレッシャー指数の倍率（`PressureModel.Multiplier`）の**生の振れ** raw＝(精神力−50)/50×slope×P に掛かる側
  - **◎**: 圧による低下を消し、わずかなプラスまで持ち上げる＝ raw' = max(raw, +`clutch_floor_per_pressure`×P)
    （精神力が高くて既にプラスなら何も足さない＝精神力の上に積まない）
  - **×**: 低下を拡大し、精神力が高くても圧で少しは落ちる＝ raw' = min(raw×`choke_negative_amplify`（raw<0のとき）, −`choke_ceiling_per_pressure`×P)
  - 伝令・主将の緩和、疲労・動揺の負側増幅は、この raw' の負側にこれまでどおり掛かる
- 効く場面: 打者（チャンス）は**得点圏に走者がいる打席**、投手（ピンチ）は**得点圏に走者がいる打席か、終盤（8回〜）の接戦（2点差以内）**
- 効く量は倍率の経路そのまま＝打者はミート、投手は制球（PressureModel.ApplyBatter / ApplyPitcher）

## 1. スキルとして「残るもの」の基準

「これはパラメータや精神力システムで出せるか？」を問い、出せないものだけを残す。

| 残す理由 | 説明 |
|---|---|
| 非線形な挙動 | 数値の線形補正では表せない「効き方の癖」（尻上がり、ムラっけ等） |
| 質的なスタイル | 数値の高低ではない打ち方・投げ方の個性（流し打ち、初球から振る等） |
| チームへの波及 | 本人の能力ではなく他選手・チームに作用（ムードメーカー等） |
| 体質・成長 | 能力値ではない体の性質（故障しにくい、練習熱心等） |
| 特定条件の技 | パラメータ化しない稀な状況技（特定投法の職人技等） |

## 2. カテゴリ別ラインナップ（純化後）

### 2.1 打撃系（挙動の癖・スタイルのみ）
- 目慣れ（旧「尻上がり（野手）」。打席を重ねるほど当たりが出る：試合内の非線形な調子。ID `SlowStarterBat` は据え置き・効果も同じ）
- ムラっけ（好不調の振れ幅が大きい：両刃）
- 初球から振る（初球スイング傾向。積極性という行動特性）
- 粘り打ち（ファウルで粘り球数を稼ぐ：行動特性）
- チャンス◎／チャンス×（得点圏でのプレッシャーの受け止め方。§0.1。◎と×は同時に持たない）
- 速球打ち（ストレート系＝ストレート・ツーシームの球に対してミートが上がる）
- 変化球打ち（変化球に対してミートと選球眼が上がる＝空振り・ボール球振りが減る）
- 流し打ち（逆方向の打球が強い＝逆方向へ飛んだ打球の初速が上がる。引っ張りに偏らない方向の質も持つ。
  **旧「広角打法」を廃止して置き換え**、古いセーブの広角打法は流し打ちとして読む＝2026-11-14 監督決定3）
- つなぎの打撃（走者がいる打席で、打球が右方向・低い角度に寄り進塁打になりやすいが、打球の質が少し落ちてヒットになりにくい。両刃）
  - 性格④「自己犠牲⇔目立ちたがり」とは効き先を分ける（2026-11-14 監督決定4）: **性格＝バントの成功率、スキル＝打った打球の方向・質**

### 2.2 投手系（挙動の癖のみ）
- 尻上がり（イニングを追うごとに安定：試合内の非線形）
- 立ち上がり難（1〜2回は制球・球威が落ち、3回からは普段どおり。尻上がりと両方残す＝2026-11-14 監督決定2:
  尻上がり＝回が進むと良くなる／立ち上がり難＝序盤だけ悪い）
- 打者一巡（2巡目以降に崩れやすい／逆に対応する：対戦回数依存の癖）
- 荒れ球（軌道が不安定で打ちにくいが四球も増える：両刃の質）
- クセ球（見た目より打ちにくい球質：物理では出しにくい質的個性）
- ピンチ◎／ピンチ×（ピンチでのプレッシャーの受け止め方。§0.1。◎と×は同時に持たない）
- クイック◎／クイック×（走者ありのクイックの秒が短い／長い＝盗塁の守備側の秒 `pitcher_quick_seconds` を投手ごとに±。◎と×は同時に持たない）
- 火消し（途中から登板したとき、登板直後の数人に制球・球威が上乗せされる。ブルペンの概念は廃止済みなので
  「肩を作る時間」ではなく「登板直後の上乗せ」＝2026-11-14 監督決定5。継投AIはリリーフを選ぶとき火消しを優先する）
- ※「制球が良い」「打たれ強い」は各パラメータで表現するためスキルにしない

### 2.3 守備系 → 廃止（issue #907）
- 併殺の名手・名捕手は削除した。守備の巧拙は守備・肩・送球精度・リードのパラメータで表す
- 古いセーブに残っている削除済みスキル名は、読み込み時に黙って読み飛ばす（`PlayerSaves.SkillSetFromJson`）

### 2.4 チーム系（本人以外へ波及＝パラメータで出せない）
- ムードメーカー（チーム士気の底上げ）
- 精神的支柱（主将適性。設計書09 §8の統率力に寄与）
- 練習リーダー（周囲の練習効率に微ボーナス）
- お手本（同ポジション後輩の成長を促進）

### 2.5 体質・成長系（能力値でない体の性質）
- 練習熱心（経験値効率アップ）／ サボり癖（負）
- 故障しにくい（怪我判定を軽減。設計書03 §3.5）／ ケガしやすい（負）
- スロースターター/早熟の体質（成長タイプの現れ方に作用）
  ※「疲れにくい（Tireless）」は選手疲労の廃止（2026-07-17）に伴い削除

## 3. 取得・喪失

- **生成時**: 才能・性格に応じて0〜数個を保有
- **後天取得**:
  - 練習の積み重ねで習得判定（長期の投げ込みで挙動が安定し「クセ球」発現、等）
  - イベントで習得（設計書03 §5.5/5.6と連動。覚醒時に有益スキル付与など）
  - 実戦経験で条件付き習得
- **喪失・克服**:
  - 負スキルはイベント/成長で克服できる余地を残す
  - 恒久喪失は原則作らない（理不尽回避）。スランプでの一時機能停止はあり得る

## 4. 元祖リスペクトの目玉スキル（少数の華）

- **「持っていたら試合が変わる」級の稀少スキルを数種**だけ用意（ばらまくと薄まる）
- 例: 「怪物」（複数分野に強力補正の超レア）、「特定投法の妙」（投法×質の職人技）など
- 出現は極めて稀。1プレイに何度も会わないからこそ記憶に残る（設計書04の怪物枠と呼応）

## 5. UI・実装

- 選手詳細（設計書06 §3.2）にスキル欄。アイコン＋短文説明（「どんな時に効くか」）
- 気づきイベント（設計書03 §5.6）でスキルの存在を部分開示（隠しスキルは育成眼で気づく）
- データ駆動: data/skills.yaml で定義（id・カテゴリ・効果・取得条件）。Claude CodeがYAML編集で追加可
- 効果は物理層/パイプラインへの補正として実装（設計書01の構造は不変）
- 検証（設計書07）: スキル保有分布と勝率寄与を集計し、壊れ性能がないか確認
