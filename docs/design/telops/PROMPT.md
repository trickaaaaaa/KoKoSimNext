# 試合テロップ（プレイボール・判定・ホームラン・ゲームセット）の実装

試合中に出すテロップを実装してほしい。見た目はすべて、このフォルダの透過PNGに焼き込み済み。
UI Toolkitでは文字を斜めに傾けたり、影を何重にも重ねたりできないため、文字は描かずに画像を表示し、動き（位置・拡大率・透明度）だけをコードで付けること。

## 進め方

1. まずコードを変更せずに、次の3点を調べて報告して。
   - 今の試合UIの構成（UXML／USS／View、試合を再生する仕組み）
   - エンジンが出すタイムラインのイベントのうち、下の「表示するタイミング」に使えるもの
   - 足りないイベントや判定材料があるか（特に「ライン際の打球」「クロスプレー」が判別できるか）
2. 報告を確認してから実装に入る。テロップはViewだけで完結させ、エンジンのイベントを受けて再生するだけにする。

## 素材の取り込み

- このフォルダを `Assets/UI/Telops/` に置く（`PROMPT.md` と `Licenses/` は取り込まなくてよい）。
- インポート設定は、Texture Type を Sprite（2D and UI）、ミップマップなし、圧縮なし（または高品質）にする。
- PNGは2倍解像度で書き出してある。画面に出す大きさは、1600×900を基準にした座標で**PNGのピクセル数の半分**にする（例：call_strike.png は930×290pxなので465×145）。実際の解像度に合わせた拡大縮小は、PanelSettings の Scale With Screen Size（基準1600×900）に任せる。
- 同じテロップの中の画像（PlayBallの3枚、GameSetの3枚、HomeRunの17枚）は、すべて同じサイズ・同じ位置合わせで書き出してある。中央をそろえて重ねるだけでずれない。
- 書体はフォントとして同梱せず、画像に焼き込んである。どちらのフォントも SIL OFL なので、念のため `Licenses/` の内容をクレジット画面などに載せておくこと。

## 共通ルール

- 位置は、特記がなければ画面中央（1600×900基準で 800, 450）。
- テロップを表示している間も、試合の操作は止めない（入力を奪わない）。
- 表示中に次のテロップが来たら、今のものをすぐ消して新しいものを出す。ただし、ホームラン・プレイボール・ゲームセットは途中で打ち切らない。
- 試合の再生速度（倍速など）の設定があれば、テロップの時間もそれに合わせて縮める。委任・スキップ中は出さない。
- イージングの対応は次のとおり。DOTweenがあれば括弧内の名前で、無ければ自前のイージング関数で実装してよい。
  - OutExpo＝cubic-bezier(0.16, 1, 0.3, 1)
  - InExpo＝cubic-bezier(0.7, 0, 0.84, 0)
  - OutBack＝cubic-bezier(0.34, 1.56, 0.64, 1)
  - InQuad

## 1. プレイボール（試合開始時に1回、合計約4.0秒）

右から流れてきて少し中央で止まり、左へ抜けていく。

**重ね順（下から）**

| 順 | 素材 | 内容 |
|---|---|---|
| 1 | 暗幕 | 全画面に `rgba(14,12,10,0.16)` の単色を敷き、その上に `playball_dim.png`（1600×900、中央が濃い楕円）を重ねる |
| 2 | スピード線 | VisualElementで作る（下の表） |
| 3 | （欠番） | 巨大な「PLAY BALL」の白い縁取り文字は**出さない**（2026-11-21 監督決定＝やかましい。素材も削除済み） |
| 4 | `playball_shadow.png` | 墨色の影 |
| 5 | `playball_extrude_mask.png` | 白い型。**スクールカラーで着色する**（`-unity-background-image-tint-color` に学校のアクセント色を指定） |
| 6 | `playball_face.png` | 白い文字と墨色の縁取り |
| 7 | `playball_sub.png` | 小さい「PLAY BALL」。その左右に、スクールカラーの横棒（64×4px）を16px離して置く |

**位置（1600×900基準）**
- 4〜6の文字本体は、中心を (800, 423) に置く。
- 7の小さい英字は、中心を (800, 541) に置く。

4〜7はひとまとまりで動かす。

**スピード線**（左上の座標と大きさ。角丸は線の太さの半分）

| 左上の位置 | 幅×太さ | 色 |
|---|---|---|
| (200, 318) | 520×3 | 白、不透明度0.85 |
| (820, 352) | 360×2 | 白、不透明度0.6 |
| (520, 560) | 640×4 | スクールカラー |
| (120, 600) | 300×2 | 白、不透明度0.7 |
| (1080, 520) | 260×2 | 白、不透明度0.5 |

**タイムライン（秒）**

| 対象 | 動き |
|---|---|
| 文字のまとまり（4〜7） | 0.00→0.65 で x を +1800 から 0 へ（OutExpo）。0.65→3.20 で 0 から −32 へ等速でゆっくり流す。3.20→3.90 で −32 から −1900 へ（InExpo） |
| スピード線（2） | 1回目は 0.00→0.55 で、まとめて x を +1700 から −1700 へ。不透明度は 0.1秒で1になり、終わりで0に戻す。2回目は 3.15→3.85 で同じ動きを繰り返す（最大の不透明度0.9） |
| 暗幕（1） | 0.00→0.60 でフェードイン、3.40 まで保つ、3.40→4.00 でフェードアウト |

モックでは、入るときと出るときに文字の傾きも変わっている（−26°→−8°）。UI Toolkitでは傾きを動かせないので、この演出は省略する（画像は−8°の傾きで焼き込み済み）。

## 2. 判定テロップ（よく出るので控えめに。流さず、その場でパッと出す。約1.9秒）

素材は `Calls/` の次の11枚。

| 素材 | 表示 | 色 |
|---|---|---|
| call_strike.png | ストライク | 黄 |
| call_strikeout.png | 三振 | 黄 |
| call_ball.png | ボール | 緑 |
| call_walk.png | フォアボール | 緑 |
| call_hitbypitch.png | デッドボール | 緑 |
| call_out.png | アウト | 赤 |
| call_doubleplay.png | ダブルプレー | 赤 |
| call_safe.png | セーフ | 緑 |
| call_foul.png | ファール | 黄 |
| call_fair.png | フェア | 青 |
| call_error.png | エラー | 紫 |

**動き**
- 0.00→0.19：拡大率 1.45→1、不透明度 0→1（OutBack。少し弾んで止まる）
- 0.19→1.68：そのまま表示
- 1.68→1.92：拡大率 1→1.04、不透明度 1→0（InQuad）
- 暗幕は敷かない。

**表示するタイミング（案）**
1つのプレーで出す判定テロップは1つだけにする。複数当てはまるときは、「三振」「フォアボール」「ダブルプレー」のように結果をまとめた方を出す。
手順1の報告で、エンジンのイベントと対応できるか確認すること。判定材料が足りないものは、報告にその旨を書く。

| 表示 | 出す条件 |
|---|---|
| ストライク | 見逃し・空振りのストライク。ファウルによるストライクは「ファール」を出す |
| 三振 | 3つ目のストライクで三振が成立したとき。このときは「ストライク」「アウト」を出さず「三振」だけを出す（振り逃げで生きた場合も「三振」） |
| ボール | ボールの判定。4つ目のボールのときは出さない |
| フォアボール | 四球が成立したとき。このときは「ボール」を出さず「フォアボール」だけを出す（申告敬遠も「フォアボール」） |
| デッドボール | 死球のとき |
| ファール | ファウルボール |
| フェア | ライン際（ファウルラインから一定距離以内）に落ちたフェア打球のときだけ。普通の打球では出さない |
| アウト | アウトが成立したとき（フライ、ゴロ、タッチ、フォース。三振は「三振」を出す） |
| ダブルプレー | 1プレーでアウトが2つ以上成立したとき。このときは「アウト」を出さず「ダブルプレー」だけを出す（三重殺もダブルプレーで代用） |
| セーフ | 送球やタッチを競り合ったクロスプレーでセーフになったときだけ。普通の安打では出さない |
| エラー | 失策が記録されたとき |

## 3. ホームラン（どちらのチームが打っても同じ演出。約3.2秒）

**素材**
- `homerun_base.png`：文字の土台（縁取り、赤い厚み、影）
- `homerun_gold_00.png`〜`homerun_gold_15.png`：土台の上に重ねる金色の面。光の筋が左から右へ走る16コマ

**重ね順（下から）**
1. 暗幕：全画面に `rgba(14,12,10,0.24)` の単色
2. `homerun_base.png`
3. `homerun_gold_XX.png`（コマを差し替えて再生）

2と3はひとまとまりにして、画面中央に置く。

**タイムライン（秒）**

| 対象 | 動き |
|---|---|
| 文字のまとまり（2・3） | 0.00→0.36 で拡大率 0.55→1、不透明度 0→1（OutBack）。2.80 まで表示。2.80→3.17 で拡大率 1→1.04、不透明度 1→0 |
| 金色の面（3） | 最初は00番のコマを出しておく。0.43→1.15 で 00→15 を順に再生する（約22fps）。そのあとは15番のまま |
| 暗幕（1） | まとまりと同じタイミングでフェードイン・フェードアウト |

回転する光の放射やキラキラは付けない（自校・相手の区別もしない）。

## 4. ゲームセット（試合終了時に1回、合計約4.0秒）

プレイボールと対になる演出。作り・重ね順・位置・タイムラインは **1. プレイボールとまったく同じ**で、素材と色だけを差し替える。

| プレイボールの素材 | ゲームセットで使う素材 |
|---|---|
| playball_shadow.png | GameSet/gameset_shadow.png |
| playball_extrude_mask.png | GameSet/gameset_extrude_mask.png |
| playball_face.png | GameSet/gameset_face.png |
| playball_sub.png | GameSet/gameset_sub.png（小さい「GAME SET」） |
| playball_dim.png | PlayBall/playball_dim.png をそのまま使う |

**色の違い**
- 厚みの型（extrude_mask）の着色は、スクールカラーではなく**濃紺 `#24324a` に固定**する。勝っても負けても同じトーンで出すため。
- 小さい英字の左右の横棒は白にする。
- スピード線のうち、プレイボールでスクールカラーだった1本は濃紺 `#24324a` にする。

**出すタイミング**
試合終了が確定したとき（サヨナラ・コールドも含む）。結果画面に移る前に再生し終える。

## 完了条件

- テロップを1つずつ手動で出せるデバッグ用の操作を用意する（例：デバッグメニューやキー操作）。
- プレイボール・判定11種・ホームラン・ゲームセットの見た目と動きが、`Mocks/` の参照モック（Claude Designのソース。`{{accent}}` は学校のアクセント色）と一致している。
- 判定テロップが連続で来ても、表示が重ならず、表示待ちの行列も溜まらない。
- 再生速度の設定と、委任・スキップ中の非表示が効いている。
- 1球ずつ判定テロップが出ても、試合のテンポが悪くならない。テンポが悪いと感じたら、表示時間の短縮を提案すること。
